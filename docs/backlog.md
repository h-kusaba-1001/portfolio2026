## 7. 運用上の注意（踏んだ罠の記録）

| # | 内容 |
|---|---|
| 1 | **コンテナ内でファイルを作る操作は `-u sail` で行う。** root で実行すると `vendor/` `node_modules/` が root 所有になり、`sail` の各コマンドが軒並み `EACCES` で失敗する |
| 2 | **デプロイは `./bin/deploy.sh` を使う。** `composer install --no-dev` は `laravel/sail` 自体を消すため、その後 `sail ...` を呼ぶ手順は必ず失敗する |
| 3 | **AWS はアカウントの Lambda 同時実行上限を自動で引き上げることがある。** 引き上げられると ADR-016 の「費用の天井」が消える。`aws lambda get-account-settings` で現在値を確認できる |
| 4 | 設定ファイル（`config/*.php`）の中で `app()` を呼ばない。読み込み時点ではコンテナが未準備 |
